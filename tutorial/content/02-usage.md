# 本站使用指南

本社团的 AI 站点由三部分组成：

```text
chat.wfla-ailab.top/portal   门户页：三个站点的跳转入口
chat.wfla-ailab.top          聊天站：用 Agent 聊天
chat.wfla-ailab.top/arena    擂台：创建/浏览/试聊 Agent、串工作流（自动登录）
tutorial.wfla-ailab.top      本站：教程
```

> 注：擂台已停用投票/排行榜，保留「创建 Agent 练习」「收藏」「留言」「每周主题」和「工作流」。

## 一、登录

管理员会给你一个账号（邮箱 + 密码）。打开 `chat.wfla-ailab.top` 登录即可。擂台（`/arena`）和教程站**共用同一个账号**，登录一次就行（擂台会自动识别聊天站的登录状态）。

## 二、站点导航与门户

三个站点共用一个账号，想快速跳转？

- **门户页**：打开 `chat.wfla-ailab.top/portal`，有三张醒目的大卡片（聊天站 / 擂台 / 教程站），点卡片直接跳转；
- 擂台和教程站顶部都有「门户 / 聊天站 / 教程站（或擂台）」的导航链接，随时互跳；
- 聊天站没有导航条，需要时在地址栏域名后加 `/portal` 就能回到门户。

> 每个站点都有一个专属管家 Agent，在聊天站侧边栏找它们提问：**聊天站管家**（站点使用）、**擂台管家**（擂台玩法）、**教程写作**（写教程文章）。

## 三、怎么用 Agent 聊天

1. 登录后，点屏幕最左侧的**「打开侧边栏」**按钮（v0.11 的侧边栏默认是折叠的）。
2. 侧边栏里能看到预置的 Agent 对话：通用助手、深度思考、代码助手、招新问答助手，以及三位站点管家（聊天站管家、擂台管家、教程写作）。
3. 点一个（比如「通用助手」），直接开聊。

**注意**：预置对话的模型是**锁定的**（比如「代码助手」只能用代码模型），切换模型会被拦截，这是故意的——每个 Agent 就该固定用它的人设。想自由选模型？点「新建对话」即可。

## 四、自己创建 Agent（练习）

擂台（arena）里有「创建 Agent」页面：

1. 打开 `chat.wfla-ailab.top/arena`（自动登录）。
2. 点「创建 Agent」，填：名称、分类（学习/社团/其它）、介绍、**系统提示词**、基础模型、示例问题等。
3. 提交时系统会用你的「示例问题」**自动试跑**一遍，把结果给你看。
4. 提交后进入「待审核」，管理员通过后就上架。

**系统提示词是最重要的**——它决定 Agent 的性格和规则，写得好不好直接决定 Agent 强不强（写作技巧见「提示词与参数技巧」教程）。

创建好 Agent 之后，还可以把它和其他 Agent 串成**工作流**（流水线），让多个 Agent 接力干活——见「Agent 流水线」和「把 Agent 串成工作流」两篇教程。

## 五、收藏与留言

- 在擂台里看到喜欢的 Agent，点「收藏」，之后在「我的 → 我收藏的」里找。
- 点「预览」可以看它的系统提示词（学习别人怎么写），还能留言给作者提建议。

## 六、每周主题

擂台顶部每周会显示一个主题（例如「做一个帮你学某一科的 Agent」）。你可以按主题创作 Agent 提交，这是社团的每周活动。

## 七、安全规则（必读）

- 不要在聊天里发**密码、身份证号、家庭住址**等隐私。
- 不要拿擂台当免费 API 刷量——试聊有限流，浪费预算会被管理员限号。
- 不要做涉及暴力、违法、仇恨内容的 Agent。
- DeepSeek 按量付费，大家省着用，看「DeepSeek 基础与预算」教程。

## 八、遇到问题

先看教程站的另外几篇教程；还不行就找管理员（他能看服务器日志和配置）。
