# 提示词与参数技巧

提示词（Prompt）是你和 AI 之间的「说明书」。**同样的模型，提示词写得好不好，效果可以差一个量级。**

## 一、系统提示词：给 Agent 立人设

创建 Agent 时填的「系统提示词（System Prompt）」是最重要的。好的系统提示词一般包含四部分：

| 部分 | 内容 | 例子 |
|---|---|---|
| **角色** | 你是谁 | 「你是高中数学竞赛教练」 |
| **目标** | 你要达成什么 | 「帮助学生掌握解题思路」 |
| **规则** | 你被允许/禁止做什么 | 「先引导思考，不直接给答案」 |
| **输出格式** | 回答长什么样 | 「先给思路，再给完整解法」 |

一个完整的例子：

```text
你是高中数学竞赛教练。
目标：帮助学生独立掌握解题思路。
规则：
1. 先指出考点和思路，不直接给答案；
2. 鼓励学生先自己尝试；
3. 最后给出完整解法并总结方法。
输出：分步讲解，公式用代码块展示。
不要使用 emoji。
```

## 二、常见写法套路

- **给例子**：想要某种风格的输出，先给一个「像这样的」例子。
- **限制范围**：明确「只回答编程问题」「不知道就说不知道」，防止 AI 胡说。
- **禁止项写清楚**：不要 emoji、不要自称有笔记/日历功能、不要说做不到的事。
- **分步骤**：让 AI「先想清楚再回答」（配合 reasoning 模型效果更好）。

## 三、坏例子 vs 好例子

坏：「你是一个助手，回答我的问题。」——太模糊，谁都能答。

好：

```text
你是社团招新接待员。用热情简洁的中文介绍社团：
我们是一个高中生 AI 社团，组织讲座、Agent 开发和竞赛。
不确定的信息如实说明，并建议联系管理员。
不要使用 emoji。
```

## 四、参数怎么调

创建 Agent 时还有几个参数：

| 参数 | 含义 | 建议 |
|---|---|---|
| **temperature（温度）** | 0~2，越高越有创意/越飘，越低越严谨/越稳 | 写作创意用 0.8~1.0；事实问答用 0.2~0.5 |
| **top_p** | 核采样，一般保持 1 就行 | 不熟就别动 |
| **max_tokens** | 回答最大长度 | 长文调大，问答默认即可 |

> DeepSeek-R1（深度思考）不支持 temperature/top_p，别给它设这些。

## 五、实用小抄

- 想让 AI 检查自己的答案：加一句「先检查你的推理有没有漏洞，再输出最终答案」。
- 想让输出结构化：加「用列表/表格/JSON 输出」。
- 想省 token：加「回答尽量简短」。
- 想防止乱编：加「不确定的就说不知道，不要编造」。

## 练习

去擂台「创建 Agent」：

1. 写一个「帮我制定学习计划」的 Agent，试试不同 temperature 的效果。
2. 故意写一个模糊的系统提示词，再写一个详细的，对比同一个问题的回答质量。
