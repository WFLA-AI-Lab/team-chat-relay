# DeepSeek 基础与预算

本站所有 Agent 都跑在 **DeepSeek 官方 API** 上，按 token 计费。这篇讲清楚：DeepSeek 是什么、怎么省钱、API Key 怎么管。

## 一、DeepSeek 是什么

DeepSeek（深度求索）是一家中国 AI 公司，提供开源大模型和官方 API。我们用的模型有两个：

| 模型 ID | 是什么 | 特点 | 适合 |
|---|---|---|---|
| `deepseek-chat` | DeepSeek-V3 系列 | 快、便宜、通用 | 日常问答、写作、代码 |
| `deepseek-reasoner` | DeepSeek-R1 系列 | 慢、贵一点、会「思考」 | 复杂推理、数学、难题 |

「深度思考」Agent 用的就是 reasoner，所以它回答更慢但更严谨。

## 二、怎么计费：按 token

- **token**：模型处理文本的最小单位，大约 1 个汉字 ≈ 1~2 个 token。
- 输入和输出都计费，输出通常更贵。
- 回答越长、对话历史越多，消耗越多。

费用 = 所有成员用量的总和。**10 个人随便聊，一个月也可能花掉几十上百元**，所以要管预算。

## 三、怎么省钱（重要）

1. **设余额告警**：platform.deepseek.com → 设置余额提醒（比如剩 10 元提醒）。本站服务器每天 08:30 会自动检查余额，低于 10 元会警告。
2. **用 chat 不用 reasoner**：日常问答用 `deepseek-chat`，只有真需要深度推理才用 R1。
3. **别让 AI 刷长文**：普通问答把 max_tokens 调小。
4. **别把提示词当聊天记录**：不要每次把整段历史重复贴进去。
5. **本站的防护**：
   - 擂台试聊有限流（每分钟 10 条、每天 100 条）。
   - 主站聊天每人每天最多 300 条消息（管理员可调）。
   - 这是保护预算的，别想办法绕。

## 四、API Key 怎么管

- Key 长这样：`sk-xxxxxxxx`，在 platform.deepseek.com → API Keys 创建。
- **Key 等于钱**，泄露给别人 = 别人花你的钱：
  - 只放在服务器环境变量 / 配置文件里，**绝不写进网页前端或发给别人**。
  - 需要分享时，用管理员统一管理，不把 Key 直接给成员。
  - 怀疑泄露：立刻去平台**作废重建** Key。

## 五、本站管理员怎么做

- 看余额：服务器上跑 `./scripts/check-balance.sh`。
- 备份：`./scripts/backup.sh`（每天 03:15 自动备份，保留 7 天）。
- 调限额：主站 Admin Panel → Functions 里改「每日消息限额」的数值。

## 练习

1. 去 platform.deepseek.com 看当前余额，确认告警设置。
2. 对比同一个问题问「通用助手」（chat）和「深度思考」（reasoner），感受速度与质量差异。
3. 想想：如果 10 个人每天各聊 50 条消息，一个月大概要花多少钱？（估算即可）
