# 术语表：这些词到底是什么

教程和站子里会反复出现一些词。这篇按「最常被问」的顺序把它们一次讲清。每个词给一个高中生活化的类比，先记类比，再看准确定义。

## 一、模型相关

### 1. 大语言模型（LLM）

读遍了几乎整个互联网文本、学会「下一个词该接什么」的程序。它不查标准答案，是**按概率续写**，所以偶尔会一本正经地说错话（这叫幻觉，见第四节）。DeepSeek-V3、DeepSeek-R1 都是 LLM。

### 2. DeepSeek-V3 与 R1 的区别

| | DeepSeek-V3 | DeepSeek-R1 |
|---|---|---|
| 定位 | 通用对话，快 | 深度推理，慢但严谨 |
| 类比 | 反应快的同学 | 爱打草稿的同学，答题前先在草稿纸上推演一遍 |
| 适合 | 日常问答、写作、翻译 | 数学、物理、逻辑、复杂规划 |

站子里选模型就一句话：**平时用 V3，难题用 R1。**

### 3. Token

模型眼里的「字块」。一个汉字大约是一个 token，一个英文单词约一到两个。模型按 token 计费、按 token 限长，所以「最大输出 token」就是回答的长度上限。类比：把文章剪成固定大小的小纸条，一张纸条就是一个 token。

### 4. 上下文窗口（Context Window）

模型一次能「看见」的 token 总量，包括你说的、它答的、系统提示词，全部算在内。超出窗口的最早内容会被忘掉。类比：一张固定大小的书桌，摊开的书太多就得撤掉最早的几本。

## 二、调教 Agent 相关

### 5. 系统提示词（System Prompt）

Agent 的人设加规则，决定它是谁、怎么干活。你写「你是高中数学教练，先引导再给答案」，它就按这个来。擂台上创建 Agent，本质上就是写好这段话。

### 6. 温度（Temperature）

控制回答的「敢想程度」。低（0~0.3）稳妥保守，适合数学和代码；高（0.8 以上）脑洞大开，适合创意写作。类比起草稿时的状态：温度低是「每一步都检查」，温度高是「先发散再收敛」。

### 7. Top_p

和温度类似的另一种控制随机性的旋钮，控制在「候选词池」的大小。一般保持默认值 1，不用动。

### 8. 提示词（Prompt）与提示词工程

Prompt 就是你发给模型的每一条消息；提示词工程是「怎么把话说清楚，让模型稳定给出你要的结果」的技巧，见第 03 篇教程。

## 三、工作流相关

### 9. Agent 工作流 / 流水线（Pipeline）

把多个 Agent 按顺序串起来，前一步的输出自动变成后一步的输入。比如「出题 Agent → 批改 Agent → 讲评 Agent」。在擂台的「流水线」页创建，每一步可以引用别人的 Agent，也可以自定义步骤。

### 10. 快照与引用

流水线步骤引用一个 Agent 时，用的是它的**最新设定**；Agent 被删除时，步骤回退到创建时的**快照**继续工作。类比：引用 = 订阅实时更新的讲义；快照 = 复印了当时那一版。

## 四、问题与安全相关

### 11. 幻觉（Hallucination）

模型按概率续写，编不出事实时就「编一个像真的」。所以**事实类答案要交叉验证**，尤其是年份、引用、数据。

### 12. API 与 API Key

API 是程序访问 DeepSeek 的通道；API Key 是钥匙，泄露了别人就能花你的额度。站子的 Key 由管理员保管在服务器 `.env` 里，永远不会出现在网页上。

### 13. 限流（Rate Limit）

为防止滥用设置的频率上限。本站：聊天站每人每天 300 条；擂台试聊每分钟 10 条、每天 100 条。这不是不信任你，是社团的预算要让大家用到期末。

## 记住一句话

模型是大脑，系统提示词是人格，token 是度量衡，温度是性格旋钮；把 Agent 串起来就是工作流；幻觉要验证，Key 要保密，限流是共享的底线。
